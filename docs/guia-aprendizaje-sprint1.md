# Guía de Aprendizaje - Sprint 1: Fundamentos de TaskFlow

## 🎯 Objetivo del Sprint
Al finalizar este Sprint, el equipo será capaz de crear, listar y eliminar tareas básicas en una interfaz web, aplicando buenas prácticas de control de versiones.

## 📚 Conceptos Clave a Aprender
1. **Git y GitHub:** Ramas, commits atómicos, Pull Requests y resolución de conflictos.
2. **Desarrollo Web:** Estructura HTML semántica, estilos CSS básicos y manipulación del DOM con JavaScript.
3. **Metodología Ágil:** Daily standups, tablero Kanban y revisión de Sprint.

## 🛠️ Entregables del Sprint
- [ ] Repositorio configurado con las plantillas de Issues y PRs.
- [ ] Interfaz básica (UI) que muestre un formulario de creación de tareas.
- [ ] Lógica para agregar una tarea a una lista en memoria (array).
- [ ] Lógica para marcar una tarea como completada.
- [ ] Lógica para eliminar una tarea.

## 📅 Cronograma Sugerido (2 Semanas)
- **Días 1-2:** Configuración del entorno, Git, y diseño de la interfaz (HTML/CSS).
- **Días 3-5:** Implementación de la lógica de agregar y listar tareas.
- **Días 6-8:** Implementación de eliminar y completar tareas. Code Reviews.
- **Días 9-10:** Pruebas, corrección de bugs y preparación de la demo (Sprint Review).
